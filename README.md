# 🚀 Meu Primeiro Portfólio - Programa Trilhas

Este projeto é o meu primeiro portfólio desenvolvido como Desenvolvedor Front-end participante do **Programa Trilhas**. A aplicação foi construída com foco em fidelidade de design a partir do protótipo no Figma, empregando boas práticas de HTML5 semântico, CSS3 moderno com gradientes e layouts responsivos, além de controle de versão com Git e GitHub.

---

## 🌐 Demonstração Online

Acesse o portfólio em produção via **GitHub Pages**:
🔗 **[Visualizar Portfólio Online](https://pedrosoaress.github.io/meu-primeiro-portfolio/)**

---

## 🎨 Funcionalidades e Telas

- **Tela Inicial**:
  - Foto de perfil circular com enquadramento focado e borda suave.
  - Apresentação inicial e identificação profissional.
  - Botões para navegar até **Sobre mim**, **Veja meus projetos** e acesso direto aos certificados na nuvem (Google Drive).
  - Rodapé integrado com links para GitHub e LinkedIn.

- **Página "Sobre mim"**:
  - Apresentação sobre minha trajetória, afinidade com a área de tecnologia e objetivos como desenvolvedor.
  - Botão de navegação rápida de retorno ao início.

- **Página "Meus projetos"**:
  - Grade de cards responsiva (Grid 2x2 no Desktop e 1 coluna em telas mobile).
  - Vitrine com os projetos e trajetórias reais:
    - **Getcard**: Plataforma de cartões de visitas digitais e interativos NFC.
    - **Cartão Getcard**: Landing page oficial para apresentação comercial e aquisição.
    - **Currículo Lattes**: Trajetória acadêmica e produções científicas no CNPq.
    - **Experiências & Trajetória**: Perfil, histórico profissional e artigos no LinkedIn.
  - Links diretos com animação interativa no botão "Acessar projeto →".

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica (`<main>`, `<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`).
- **CSS3 Moderno**:
  - Gradiente em múltiplas camadas (Pastel Aura Effect fiel ao Figma).
  - Efeito Glassmorphism (`backdrop-filter: blur`).
  - Flexbox & CSS Grid para posicionamento e alinhamento responsivo.
  - Tipografia otimizada com a fonte *Inter* (Google Fonts).
  - Ícones vetoriais SVG de alta resolução.
- **Git & GitHub**: Controle de versão e hospedagem contínua via GitHub Pages.

## 💻 Como Visualizar Localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/PedroSoaress/meu-primeiro-portfolio.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd meu-primeiro-portfolio
   ```
3. Abra o arquivo `index.html` em qualquer navegador (ou use a extensão *Live Server* no VS Code).
